# Projet sur Programmation avec Python (Master 2 Stratégies informationnelles et documents numériques, Université Jean Moulin Lyon3)

Dans le cadre du projet « Programmation avec Python », un site web consacré à la K-pop (musique pop coréenne) sera créé au cours de la deuxième année de master. Ce projet attendait depuis longtemps d'être réalisé.



Ce site sera un portail sur lequel les utilisateurs pourront :

* lire les actualités dans le domaine de la K-pop,
* obtenir des informations générales sur les artistes,
* consulter les événements liés à la K-pop,
* consulter le rating mensuel des groupes (hommes et femmes).

Seuls le design a été repensé et adapté à Django (et non à PHP) et une partie du code permettant d'afficher les vidéos YouTube a été modifiée, car sinon les vidéos ne s'affichaient pas (nouvelle politique d'affichage des vidéos, si j'ai bien compris...).

La base de données est divisée en 3 applications principales :

* Actualités (News),
* Artistes (Artists),
* Événements (Events).
Les 2 utilisateurs peuvent être l'administrateur, l'éditeur d'actualités ou les utilisateurs du site eux-mêmes.
Pour expliquer en détail le fonctionnement du projet, le travail sera divisé en sections avec des applications du site, donc :
Général kpopsite;
Main ;
Events ;
Artists ;
News.
